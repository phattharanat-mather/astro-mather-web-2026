## Overview

An interactive, scroll-driven credential deck built for The Mather — replacing static slide decks with a fully branded web experience.

## What we built

A scroll-based storytelling layout with animated scene transitions, a chapter navigation panel, and a custom font scale system. The deck covers the company's story, services, clients, and team — all driven by structured content.

## Stack

- **Astro 6** — static rendering with React islands for interactive scenes
- **React + Framer Motion** — scroll-driven animations and scene choreography
- **Tailwind CSS** — utility-first styling scoped to the storytelling layout
- **TypeScript (strict)** — typed scene data and component props throughout
